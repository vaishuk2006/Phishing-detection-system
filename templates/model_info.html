About the System

Learn how this student cybersecurity demonstration analyzes URLs.

Project Overview

PhishGuard is a Phishing Website Detection System prototype. It examines URL characteristics and identifies warning signs that may be associated with phishing links.

01

URL Feature Extraction

Examines URL length, symbols, domain characteristics, and suspicious keywords.

02

Rule-Based Assessment

Uses basic rules to produce a demonstration risk level.

03

Scan History

Stores scan records in a local SQLite database.

Current Implementation

The current version uses rule-based URL analysis. A trained machine-learning model has not yet been connected. The results are estimates and must not be treated as proof that a website is safe or malicious.
